NVIDIA VRAM Watchdog - Production Audit
========================================

Source base
-----------
NvidiaMemoryWatchdog_NPCFRecovery_VS2022.zip (latest supplied NPCF watchdog)

Implemented production changes
------------------------------
1. Exact target verification with 1 MHz tolerance (fixes 11001/9001 targets).
2. NPCF State Unlock moved off the GUI thread.
3. Post-restart verification moved to a 100 ms UI timer (no blocking Sleep loop).
4. pnputil.exe and schtasks.exe have 15-second hard process timeouts.
5. nvml.dll loads only from System32.
6. pnputil.exe and schtasks.exe launch by absolute System32 path via lpApplicationName.
7. Successful State Unlock no longer clears the global 5-second restart cooldown.
8. NPCF matching requires canonical device name plus known hardware/instance signature.
9. User-configurable Unlock attempts (1-20, default 3).
10. Removed Hide to Tray button and duplicate in-client app title.
11. Telemetry/static/check-box backgrounds use the window background instead of gray blocks.
12. Startup-task delete is verified when schtasks reports a non-zero delete result.
13. BUILD_RELEASE.bat performs a clean Release Rebuild and verifies the EXE exists.

Recovery safety scan
--------------------
- /remove-device occurrences: 0
- RTX display-adapter restart implementation: 0
- /restart-device occurrences: 1
- That restart target comes only from strict NPCF discovery.
- Infinite process waits: 0
- Plain LoadLibraryW("nvml.dll") fallback: 0

Static validation performed in the build environment
----------------------------------------------------
- C++ delimiter/string/comment lexical balance: PASS
- Visual Studio project XML parse: PASS
- Requested production-hardening source-pattern checks: PASS
- Archive integrity: run before packaging

Important compile note
----------------------
The packaging environment is Linux and does not contain the Microsoft Windows SDK/MSVC,
so the definitive compiler/linker validation must be performed by BUILD_RELEASE.bat on
Windows with Visual Studio 2022 Build Tools.
