NVIDIA PowerState Watchdog — Production Audit
=============================================

Core behavior
-------------
- Watchdog target is the GPU P-State, not memory-clock equality.
- Supported P-States are discovered dynamically through NVML.
- Per-P-State memory ranges are queried dynamically.
- Legal NVML memory lock clocks are mapped to each P-State at runtime.
- Overclock/underclock offset is telemetry only and never causes recovery by itself.
- Normal recovery is attempted before NPCF restart.
- Target request is pre-armed before NPCF restart.
- RTX display adapter is never restarted or removed.

Overclock handling
------------------
- Uses nvmlDeviceGetClockOffsets when available.
- Falls back to nvmlDeviceGetMemClkVfOffset on older drivers.
- Mapping first tries raw P-State ranges, then offset-normalized ranges when needed.
- Current P-State remains the authoritative watchdog health check.

Power handling
--------------
- Monitoring pauses for display-off / standby.
- NVML handle is closed during low-power state.
- Low-power P-States are ignored while paused.
- Selected P-State policy is reapplied after display-on/resume.

Startup
-------
- Legacy scheduled tasks are detected and removed silently.
- Start with Windows uses HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run.
- No startup migration chatter is written to the event log.

Tray
----
- Tray menu uses Set P-State / Reset P-State.
- Hover card is dark/rounded and no-activate.
- Hover remains active only while cursor is within this app's exact tray icon rectangle.
- Telemetry includes P-State, target P-State, memory, optional memory OC, GPU clock, power and temperature.

Logging
-------
- Full date + time: [YYYY-MM-DD HH:MM:SS].
- No Watchdog: prefix.
- No State Unlock Successful/Failed wording.
- No settings-save, target-selection, checkbox, tray-hover, or per-poll spam.

Security / safety
-----------------
- nvml.dll: System32 only.
- pnputil.exe: absolute System32 path.
- pnputil hard timeout retained.
- NPCF discovery remains conservative.
- /remove-device implementation: 0.
- NVIDIA display-adapter restart implementation: 0.
